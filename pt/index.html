Projeto 01

Plataforma de IA para processos de vistos nos EUA

Uma plataforma LegalTech multiempresa que transforma critérios da USCIS e documentação dispersa num fluxo consistente, auditável e guiado por evidência.

Problema
Aplicar os critérios da USCIS a documentação dispersa de forma consistente e auditável.
Contributo
Conceção e implementação de componentes para recolha estruturada, triagem, questionários dinâmicos, gestão documental, OCR, análise com modelos de linguagem e relatórios para revisão jurídica.
Resultado
Uma arquitetura full-stack multiempresa em desenvolvimento, concebida para apoiar um processo de revisão jurídica orientado por evidência.
Python TypeScript FastAPI Next.js PostgreSQL Redis Alembic Docker OCR LLMs ClamAV Sentry
